# sprint-mvp-v11-avtoservis

## Автосервис: запись (MVP)

Информационная система для автоматизации записи клиентов в автосервис на текущий день. Предназначена для администратора автосервиса.

### Основной функционал:
* Отображение структуры главного меню программы
* Просмотр доступных свободных часовых слотов (с 9:00 до 18:00)
* Запись нового клиента на свободное время с указанием имени и марки машины
* Просмотр списка всех записей на день
* Отмена существующей записи по имени клиента
* Поиск записей по имени клиента
